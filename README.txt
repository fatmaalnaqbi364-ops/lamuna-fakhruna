مهم: هذا مشروع Netlify Functions + Netlify Blobs، وليس صفحة HTML فقط.
للنشر: ارفعي محتويات المجلد إلى مستودع GitHub ثم من Netlify اختاري Add new project > Import an existing project > GitHub.
Build command: اتركيه فارغًا. Publish directory: .
Netlify سيُثبت حزمة @netlify/blobs من package.json.
الرفع: صور وفيديو MP4/WEBM وPDF بحد أقصى 4MB. المعرض عام والنشر فوري دون مراجعة.
لا تستخدميه لجمع صور شخصية أو أسماء طالبات دون موافقة المدرسة.
تنبيه: لا يوجد دخول مدير أو حذف/موافقة في هذه النسخة. الرفع العام قد يتعرض للإساءة؛ يُنصح بتقييده قبل التوزيع الواسع.
